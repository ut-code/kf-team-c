# 社会浸透シミュレーション

AIへの過度な依存によって、人間が判断の機会と権限を手放す過程を描くリアルタイム世界シミュレーションです。

## 起動

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

配布用は `npm run build`、確認は `npm run preview`。実行時に外部サービスへ接続しないため、展示中もオフラインで遊べます。WebGLと8192pxのテクスチャへの対応が必要です。

## 画面と操作

世界地図を画面全体へ描画し、次の操作を地図上に重ねます。ヘッダー・フッター・常設サイドバーはありません。

- 左上：ニュース。クリックすると過去のニュースと本文を展開します。
- 上中央：構造的依存・AI利用・信頼・共存制度・育成に使える計算資源の小さな指標。
- 左下：年・月・日を固定幅で並べたカレンダー、一時停止、1・2・4倍速。
- 右下：能力配分・スキルツリー・小地域。クリックで開閉し、閉じると全面地図へ戻ります。
- 地図上の陸地：マウスを合わせると国ではなく小地域を選択します。クリックすると小地域パネルを開きます。
- 地図上の人口点：小地域と、その点の参照統計を調べます。
- 地図上の吹き出し：重要人物との会話を開始します。会話を開く前も、会話中も、結果を表示している間も、ゲームは進行します。閉じた未完了の会話は再開できます。

地図はドラッグ・矢印キーで移動、ホイールで拡大縮小します。点のサイズは画面上で固定し、拡大縮小しても変わりません。間隔は地図基準で、重なりを許容します。ホバーしても他地域の点を暗くしません。Spaceで一時停止・再開、Escapeで操作パネルや会話を閉じます。

初期条件の統計年に合わせて2020年から開始し、2060年までの40年間を扱います。標準速度は1か月3.125秒、最大25分です。開始前、遊び方の表示中、画面が非表示の間、手動で一時停止した間は進行しません。保存機能はなく、再読み込みでリセットします。

## ゲームの進行

維持費を除いた計算資源をIQ・EQ・SYSTEMへ配分します。配分の合計は常に100%。普及によって供給能力が増える一方、利用人口に応じて維持費も増えます。構造的依存そのものに追加の維持費はかからず、資源不足による敗北はありません。

5分野の重点、3系統9技術、SNS施策、重要人物との会話で社会に介入します。3年ごとに会話の候補が地図へ追加され、未完了の会話も残ります。能力による成立判定は回答時の値を使います。

| 色 | 状態 |
| --- | --- |
| 灰 | 自律的な判断 |
| 青 | AIを道具として利用 |
| 赤 | 判断をAIへ委譲 |
| 紫 | 社会制度を通じた構造的依存 |
| 黄 | AIの利用拒否 |

利用拒否は判断ミスや協議失敗などで発生し、AI利用率には含みません。時間経過で拒否感情が和らぎ、EQ・信頼・SNS対話によって回復が早まります。回復時は自律または道具利用へ戻ります。

紫への移行には「制度間連携」、SYSTEM 40以上、担当分野の制度化72%以上が必要です。社会の反発や人間の最終判断を守る制度は、依存を鈍化・後退させます。

4,000点すべてが紫になれば勝利。人口加重の共存制度が65%以上で24か月続く、または480か月までに勝利しなければ敗北します。

## 使用する人口・社会統計

人口点は地域の中心に散布せず、**欧州委員会JRCのGHS-POP R2023A・2020年・30秒角の実人口グリッド**から生成しています。人口の多い居住セルほど選ばれ、砂漠や山岳へ架空の点を追加しません。小地域と国の人口比に従って4,000点を割り当て、各点は数百万人規模の集団を代表します。

年齢構成・インターネット利用・都市人口・就業率・産業別就業構成には、2020年の世界銀行WDI（国連・ITU・ILO由来）の公表値を対応させます。台湾の年齢構成は、世界銀行に収録されていないため台湾内政部の公表値を明示的に収録しています。

初期位置と統計属性は再開始しても変わりません。乱数シードはゲーム内の出来事に使います。観測・公表統計と、AIへの信頼や浸透速度などのゲーム用モデルは区別しています。欠測値は別の国や架空の数値で埋めず、「未収録」とします。

出典、指標コード、欠測数、抽出方法、制約、再生成方法は [統計データの説明](data/statistics/README.md) を参照してください。

## 確認

```sh
npm run check
npm run build
npm run simulate -- 3
```

通しシミュレーションは、均等育成・必須技術のみ・IQ集中・研究なしの4方針を実行し、人口点数や配分合計の不変条件も確認します。出力は `tmp/reports/simulation.json`。一時的な検証コード・原本の大型ファイル・プレビューは `tmp/` に置き、Gitへ含めません。

地図素材は `public/maps/README.md`、フォントは `public/fonts/NotoSansJP-OFL.txt`、統計データの出典と利用条件は `data/statistics/README.md` を参照してください。

計算資源の供給は `52 + (利用率×170 + 判断委譲率×130 + 構造的依存率×420) × (0.6 + 信頼×0.4)`、維持費は `12 + 利用率×48×効率係数` です。率は0〜1で扱い、効率係数は軽量化・分散社会基盤ごとに0.75倍。差分が育成に使える資源で、独自の単位表記は付けません。
