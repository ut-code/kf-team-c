# 地図の素材加工

現在はユーザー指定により地表テクスチャを無効化している。`scripts/map_studies/land-materials.json` の `enabled: false`。配信画像は地形の配色・起伏のみ。以下の素材は再調整用に保持し、描画には使用しない。

現在の地表は森林・一般地表・乾燥地・雪氷と、標高1800〜3400mで分離した高山の岩地。分類ごとに別のambientCG素材を使う。すべてCC0 1.0。

| 分類 | ambientCG素材 |
| --- | --- |
| 森林 | Ground037 |
| 草地・一般地表 | Grass004 |
| 砂漠・乾燥地 | Ground054 |
| 雪氷 | Snow001 |
| 高山・岩地 | Rock035 |

出典は `https://ambientcg.com/view?id=素材ID`。利用条件: https://docs.ambientcg.com/license/

原本は `data/materials/ambientcg/素材ID/`。設定は `scripts/map_studies/land-materials.json`、加工は `scripts/land_materials.py`。

微細な草・砂粒を面積平均で省き、素材の大きな色むらを差し引く。素材を2048px幅で配置し、低コントラスト・低彩度で元の地形に合成する。過剰な4096px幅への拡大と強い明暗は取りやめた。分類境界は各素材の明暗を利用した重み付けでつなぎ、地図全体へのぼかしは行わない。湖と海には適用しない。

加工素材は `assets/generated/map/materials/forest.png` など。128が中立となる加算用画像で、実際の明暗量を保存。最終合成は `assets/generated/map/世界地図.png`、配信は `public/maps/world-map.webp`。

海は従来の整理を維持。水深と陰影を2.4度相当で平滑化し、深海の広い濃淡・浅瀬・海岸の立体感を残す。

再生成は `npm run assets`。地形・分類マスク→海・地表素材→配信画像の順。`assets/generated/map/untextured.png` は素材・海岸加工前の中間画像、`land-mask.png` は海岸加工用マスク。`assets/generated/terrain/masks/` に5分類のマスクを保存する。

検証: `python scripts/map_studies/verify_generalized.py`、`python scripts/map_studies/verify_oceans.py`。設定と原本・出力のハッシュは各生成記録に保存。
