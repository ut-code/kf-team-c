# 船舶・飛行機の交通演出

ゲーム内の通常社会の往来として描画する。計算資源・勝敗・シミュレーション乱数には影響しない。時間停止、チャットを開いている間、勝敗確定後は止まり、1・4・16倍速に連動する。表示の移動時間は視認性に合わせた演出用で、実際の所要時間ではない。

## 経路

- 航空32路線: OpenFlightsの `routes.dat` に存在する直行接続だけを選び、`airports.dat` の空港座標を使う。路線原本は2014年の履歴データ。空港間は大圏で補間する。実際の管制ウェイポイントや日々の飛行軌跡・運航頻度を再現するデータではない。
- 船舶12経路: SeaRoute系の公開Marnet海上交通網に沿う最短経路。港付近の海上ノード間をつなぐ。元はCTA Global Shipping Lane Network（2000年）を基礎に欧州沿岸のAIS等で拡充された網。個別船のAIS航跡・船会社の運航表ではない。北西航路・ベーリング海峡は通常の演出経路から除外。
- 実在する空港・港の間をモデル化した演出。ライブ追跡ではない。

選択する空港・港は `data/transport/selection.json`。原本は `data/transport/raw/`、ハッシュは `data/transport/manifest.json`。生成は `python scripts/build_transport.py`。生成された `src/game/data/map/transport-routes.json` を配信する。

出典・利用条件:
- OpenFlights: https://openflights.org/data.php （ODbL 1.0。原記録の出典注記を含む）
- 原本: https://github.com/jpatokal/openflights/tree/master/data
- SeaRoute: https://github.com/eurostat/searoute （EUPL 1.2、`public/licenses/searoute-EUPL.txt`）
- 使用した交通網ファイル: https://github.com/genthalili/searoute-py/blob/main/searoute/data/marnet_searoute.geojson

## 描画

`src/components/TrafficLayer.tsx` のCanvasへ描画し、クリック・ドラッグを妨げない。航空機は短い飛行跡、船は短い航跡だけを添える。航路線は常設しない。位置と日付変更線の処理は `src/map/traffic.ts`。

船舶は `public/maps/water-mask.png` で海だけに切り抜く。110m地図で省略された運河の区間では船影が隠れる。横移動・画面サイズ変更にも地図と同じ投影を使う。

経路の両端の国の経済とインフラが落ちると、表示される往来も減る。経路の国IDは `data/transport/selection.json` に定義する。
