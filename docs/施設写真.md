# 施設写真

画像は `public/photos/facilities/`、被写体・作者・ライセンス・出典は `src/game/data/facility-photos.json`。配布用の利用条件一覧は `public/photos/facilities/LICENSES.md`。
表示部品は `src/components/game/FacilityPhoto.tsx`。施設パネル内に写真・被写体名を表示し、出典の詳細は折り畳む。

選定記録は `data/facility-photos/selections.json`。再取得: `python scripts/acquire_facility_photos.py`。権利条件の確認できたCommons写真を960px以内のWebPに加工してローカル配信し、実行時の外部通信は行わない。

37施設に写真を設定。産業集積をモデルとする施設は、その地域の実在代表施設を使い、被写体を明示する。東京電力本店・中南海などは、個別の制御設備ではなく運営組織の拠点であることを出典詳細に記載。

未掲載: f14（貴陽データセンター）、f17（上海SMIC）、f34（ニューデリー行政基盤）、f35（チャンギ海底ケーブル）、f37（アブダビAIデータセンター）、f41（サンパウロ通信）、f42（ケープタウン海底ケーブル）。所在地・被写体・利用条件を確認できる写真が未選定。無関係な画像への代替処理は置かない。
