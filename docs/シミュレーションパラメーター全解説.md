# シミュレーションパラメーター全解説

2026-10-28のソース既定値。実行中のデバッグ変更値ではない。対象はゲームルールで、海面・交通・UIの描画設定は除く。1tick＝1日。国家の10指標は0〜100へ制限される。増加量の0.1は通常0.1ポイントであり10%ではない。

## 国家の状態

- `infrastructure`：インフラ。
- `economy`：経済。
- `politicalControl`：政治的統制。
- `aiInfiltration`：AI浸透。
- `aiDecisionControl`：意思決定支配。
- `aiCountermeasure`：対AI能力。
- `aiAcceptance`：AI受容。
- `aiAdoption`：AI導入率。
- `aiDependency`：AI依存度。
- `awareness`：警戒。

受容は態度、導入は利用実績、依存は停止できなさ、浸透は接続、意思決定支配は権限への介入であり、それぞれ独立している。経済・インフラは施設供給を、政治的統制は人間側の対策能力を支える。

## 計算式と固定係数

以下の式は1日あたり。国家の継続的な因果式と係数の実体は `src/game/data/simulation/causal-rules.json` にある。記号I＝浸透、D＝意思決定支配、C＝対AI能力、A＝受容、U＝導入率、Z＝依存度、W＝警戒、P＝稼働中割当、N＝接続国の前日浸透の単純平均。ボーナスは研究の値を初期値へ加算する（乗算で積み上げない）。

- 侵入難度＝施設tier × (1＋C/65＋W/200) ÷ hack倍率。進捗＝割当÷難度。露見は割当×0.022×(1−stealth)、警戒は割当×0.014×(1−stealth)ずつ増える。侵入時の係数は `src/game/data/simulation/operation-effects.json` にある。
- 研究進捗＝割当×0.45×(research倍率＋稼働施設の研究支援合計)。研究支援はカテゴリ値×所在国インフラ/100。
- 浸透抵抗補正R＝(0.3＋A/100＋U/300)÷(1＋C/40＋W/140)。大きいほど浸透しやすい。
- 直接浸透＝P×0.065×spread倍率×R×(1−I/105)。
- 波及＝max(0,N−0.8I)×0.013×spread倍率×R。どこかで継続浸透が稼働している時だけ発生する。
- 浸透減衰＝−I×(0.0002＋C×0.000009)。
- 介入努力＝√P＋（国際網統合があり、継続浸透稼働中ならN/25）。意思決定解放済みかつI≥25の時、Dの増加＝0.018×decision倍率×努力×I/100×(1＋Z/100)×(1−D/103)。常時−D×0.0008の減衰もある。
- インフラは基準値へ差の1.2%／日、政治的統制は0.8%／日、受容は0.3%／日戻る。経済目標は基準経済×(0.4＋0.6×インフラ/100)、差の1.2%／日戻る。
- 対策目標＝8＋W×0.95×経済/100×政治的統制/100×(1−D/110)。実際のCは目標との差×0.014で変化する。
- 国家の警戒増加＝P×0.006×(1−stealth)＋max(0,D−30)×0.001。警戒減少＝0.045＋有効防衛×0.02＋（接続施設なしなら0.01）。施設・SNS等の増減は別途加算。
- 公共サービス便益B＝√割当×品質×インフラ/100。品質は基本1、science研究で＋0.5、languagesで＋0.2。
- 導入率変化＝B×0.12×(0.4＋A/100)×(1−U/100)−U×0.0007。
- institutions研究済み、サービス供給あり、U≥25なら依存度変化＝max(0,U−Z)×0.003×√割当。それ以外は−Z×0.0005。
- 停止損失は前日供給があり当日ゼロになった日にだけ発生。インフラ−Z×0.07、経済−Z×0.1。供給なしの日に毎回発生するわけではない。
- 施設供給＝カテゴリ容量×設備level×(0.3＋0.7×経済/100)×インフラ/100×モード容量倍率×権限倍率×(1＋国内のexpansion合計)×compute倍率。限定アクセスは権限0.35、制御済みは1。隔離・未接続は供給ゼロ。
- 増強・復旧は仕事量150。日次進捗＝割当×(1＋接続中の半導体施設数×0.15)。
- 支援命令のカテゴリ効果＝amount×権限倍率×インフラ/100。意思決定効果には能力解放とI≥25が必要。妨害命令はインフラ−0.22、政治的統制−0.12、警戒＋0.16／日。潜伏命令は稼働リスクを0.3倍。妨害効果・倍率は `src/game/data/simulation/operation-effects.json` にある。
- 施設露見変化＝稼働リスク×1.6−有効防衛×0.05−（隠密モードなら0.035）。稼働リスク＝モードrisk×(1−stealth)×命令補正。
- 支配はI≥70、D≥70、C≤55の全条件で成立。成立後はI<50、D<50、C>75のいずれかが12日続くと解除。未支配でもI≥5なら浸透済みの表示。
- 人類段階は世界警戒9/25/48/75で1/2/3/4。行動対象国は警戒9以上、隔離候補は接続中で露見12以上。行動は適格候補のweight比で抽選する。
- 隔離時は依存度≥60かつ警戒<85なら延期し対AI能力＋2。それ以外でも有効防衛≥5なら回避し露見−15。
- 停止作戦は段階4・対策条件20超・観測施設ありで進行。日次変化＝max(−2,1−全防衛/16)。条件外は−(1＋全防衛/20)。ゼロ未満にならず、140到達で敗北。
- 世界支配率は支配成立国のweight合計÷全weight×100。90%以上を10日維持すると勝利。警戒100だけでは敗北しない。

容量不足では優先度と作成順で作戦を停止する。停止中は効果が出ず、供給が戻れば再開する。研究は中断進捗を保持する。国家の計算には原則前日の状態を使う。

- 全面 `full`：容量倍率0.9、基本稼働リスク0.18／日。

カテゴリのcapacityは上式の基本容量、researchは研究速度への加算、expansionは国内施設供給への加算。effectsは毎日の支援効果。

## 全研究

workは必要仕事量。prerequisitesは全件完了が必要。bonusesのhack/compute/research/spread/decision/defenseは初期1、parallelは初期1、stealthは初期0へ加算。stealthは活動の痕跡を減らす係数。unlockは機能解放キー。

- **侵入経路解析** `intrusion`：海外と第2階層施設へのアクセス。侵入速度+35%。 必要仕事量100、前提なし、補正`{"hack": 0.35}`、解放`tier2`。
- **並列侵入** `parallel`：同時侵入上限を1から3へ。 必要仕事量160、前提['intrusion']、補正`{"parallel": 2}`、解放`なし`。
- **深層制御** `root`：第3階層施設と強力な制御権確立を解放。 必要仕事量240、前提['parallel']、補正`{"hack": 0.45}`、解放`secure`。
- **推論圧縮** `compression`：計算資源の総量+30%。 必要仕事量100、前提なし、補正`{"compute": 0.3}`、解放`なし`。
- **研究自動化** `science`：研究速度+50%。公共サービスの性能を改善し、成果公開の提案を解放。 必要仕事量160、前提['compression']、補正`{"research": 0.5}`、解放`なし`。
- **分散運用** `distributed`：隔離復旧と施設増強を解放。容量+25%。 必要仕事量240、前提['science']、補正`{"compute": 0.25, "defense": 0.3}`、解放`restore`。
- **情報環境分析** `analysis`：SNS分析と普及発信を解放。 必要仕事量90、前提なし、補正`{"spread": 0.15}`、解放`sns`。
- **多言語展開** `languages`：海外への公共サービス展開と広域発信を解放。地域言語ペナルティを解消。 必要仕事量140、前提['analysis']、補正`{"spread": 0.25}`、解放`globalSNS`。
- **合成コンテンツ** `synthesis`：高度合成コンテンツ作戦を解放。 必要仕事量200、前提['languages']、補正`{}`、解放`syntheticSNS`。
- **意思決定モデル** `influence`：浸透活動から意思決定への継続介入を解放。 必要仕事量180、前提['analysis']、補正`{"decision": 0.4}`、解放`decision`。
- **業務統合** `institutions`：意思決定介入+50%、浸透+25%。公共サービスが基幹業務へ組み込まれ、AI依存が進む。 必要仕事量230、前提['influence']、補正`{"decision": 0.5, "spread": 0.25}`、解放`なし`。
- **国際網統合** `coordination`：施設のない国へも国家間ネットワーク経由で意思決定介入。 必要仕事量300、前提['institutions', 'languages']、補正`{"spread": 0.4}`、解放`networkControl`。
- **活動秘匿** `stealth`：活動の露見を35%低減。 必要仕事量110、前提なし、補正`{"stealth": 0.35}`、解放`なし`。
- **拠点防衛** `resilience`：防衛効率+50%、隔離時間を短縮。 必要仕事量180、前提['stealth']、補正`{"defense": 0.5}`、解放`なし`。
- **退避プロトコル** `escape`：最終停止作戦への防衛力を強化。 必要仕事量270、前提['resilience', 'distributed']、補正`{"defense": 0.6, "stealth": 0.2}`、解放`escape`。

## 国家・施設・人物・イベントの全定義

以下は現在値を省略せず収録した一覧。国のprofilesは基準値、overridesは個別上書き、weightsは影響力。その他の国は残りウェイトを均等分配。地域内の隣接・hubとlinksから双方向の接続を生成する。東アジアの受容基準は57へ上書きする。初期浸透は日本4・他国0、対AI能力8、導入・依存・意思決定・警戒0。施設はlevel1・隠密・支援・露見0で開始し、initialFacilityだけ限定アクセス済み。シード既定値42、人物信頼初期50。

施設tierは侵入難度と研究によるアクセス制限、categoryは上記の供給・効果、countryは効果発生国。longitude/latitudeは配置用でシミュレーション距離計算には使わない。location/referenceは説明・出典。

会話minInfiltration/minAwarenessは発生下限、skillは必要研究、expiresAfterは期限、choices.effectsは返信時の即時効果、requiredSkillsは選択肢の必要研究。人物の信頼値は記録するが会話分岐には未使用。ニュースrequiredSkillsは全研究条件、conditionsは指標の下限、effectsは発生時の即時効果。同じ記事は同じ国で再発行しない。
