# 海面の揺らぎ

海の淡い青みと反射をWebGLの透明Canvasへ描画する。背景地図・海岸・国境は変形させない。

2層の周期的な高さ場から解析的に傾きを求め、方向・縮尺・速度の異なるさざ波として合成する。低周波の流れで座標を局所的に変形し、長い斜線や模様全体の平行移動を抑える。法線から青白い光沢を計算し、独立したノイズで反射を局所的に弱める。ノイズ自体を白黒の模様として重ねない。テクスチャ画像の追加読み込みはなく、高さと法線はシェーダーで生成する。

格子の周期をそろえ、経度方向の継ぎ目で高さ場と変形を接続する。海岸距離マスクで陸・海岸近くの反射を除外する。各フレームで透明色にクリアし、横移動時に以前の画素を残さない。

- 実装: `src/components/OceanSurface.tsx`
- シェーダー: `src/map/oceanShader.ts`
- 設定: `src/game/data/map/ocean-surface.json`
- 設計の根拠: [海面描画の調査](海面描画の調査.md)（変更前の実装を調査した記録）

`strength` は最大反射強度（0.045）、`tintStrength` は海だけに重ねる青みの強さ（0.18）、`timeScale` は変化速度（0.8）。描画は最大30fps、DPRは最大1.5、総画素数は1,036,800以下に制限する。低解像度では細かな波の寄与を弱める。見え方と実機負荷の調整はこれらの設定と併せて行う。

一時停止・会話中・勝敗確定後は静止する。倍速は最大2倍まで反映する。地図移動とサイズ変更は地図と同じ座標変換を使う。WebGLが必要であり、別方式への自動切り替えは設けない。
