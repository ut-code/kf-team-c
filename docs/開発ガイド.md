# シミュレーション開発ガイド

## 責務の境界

| 変更したいこと | 編集先 |
| --- | --- |
| 国家指標の因果関係・係数・条件 | `src/game/rules/country.ts` |
| 施設の容量・露見・支援効果 | `src/game/rules/facility.ts` |
| 会話・ニュース・SNS・人類行動の効果変換 | `src/game/rules/content.ts` |
| 人類の対応段階・隔離判断・停止作戦 | `src/game/rules/human.ts` |
| 研究済みスキルからの倍率集計 | `src/game/rules/modifier.ts` |
| 侵入・増強・研究の進捗と露見 | `src/game/rules/operations.ts` |
| ニュースの選択条件 | `src/game/society.ts` と `src/game/data/events/news.json` |
| 会話・ニュースなどの文章や固定効果 | `src/game/data/events/` のJSON |
| 初期値・研究・カテゴリなどの静的設定 | `src/game/data/simulation/` のJSON |
| 命令の検証、tick順序、Effect適用、ログ・通知、状態更新 | `src/game/engine.ts` |
| 画面表示や入力操作 | `src/components/` と `src/state/` |

SNS作戦の名称・必要研究・期間・基礎効果は `src/game/data/events/sns.json`、全世界への到達倍率は `src/game/rules/content.ts`、国家への適用と完了処理は `src/game/engine.ts` を編集する。SNS命令には国指定がない。

## 関数契約

`State` はゲーム全体の保存状態、`Attribute` は国家の数値指標、`Modifier` は研究などによる倍率、`Effect` は指標への増減、`Condition` は判定条件、`Command` はプレイヤー入力、`Event` は表示する出来事。定義は `src/game/types.ts` にある。既存コード向けの `GameState`・`Metric`・`Bonuses`・`Action`・`GameEvent` は互換エイリアス。

ルール関数は必要な入力だけを引数に取り、数値・`Effect`・判定結果を返す。`State` を受け取らず、入力を変更しない。Engineは前tickの国家値と操作情報を集め、ルールの結果を適用して、ログと通知を記録する。UIはEngineの公開関数と読み取り専用の集計関数を使い、ルール計算を複製しない。

例えば導入率の変化だけを調整するなら `adoptionChange` を編集し、`tests/data.test.ts` の単体テストと `tests/game.test.ts` の固定シード回帰テストを確認する。新しい国家効果は共通の `Effect` を返し、適用と上下限処理はEngineに任せる。既存挙動を変える依頼がない限り、固定シード回帰テストの期待値を書き換えない。

```sh
npm test
node node_modules/typescript/bin/tsc -b --pretty false
```
