# 社会への導入・依存と通知

## 採用した意見

公共サービスの実績による導入、業務統合による依存、停止の代償、能力公開に伴う安全性研究、社会状態を条件にするニュース、研究による会話選択肢の解放を実装した。視点は従来の地図を俯瞰する形式を維持する。人口の排他的な思想分類、IQ/EQ/SQの能力値、複数AI、人類殲滅モードは追加しない。

## 公共サービス

国家を地図から開き「公共サービス」へ計算資源を配分する。国内は開始時から、海外は「多言語展開」研究後に実行できる。侵入・研究・防衛と同じ容量を使う。

公共サービスの性能は配分量・研究自動化・多言語展開・その国のインフラに依存する。サービスが経済・インフラ・受容を少しずつ改善し、実績が導入率につながる。公開された能力への安全性研究も進む。停止すると導入は徐々に後退する。

- AI導入率: 社会での利用の広がり、0〜100%。浸透度や支配率とは別。
- AI依存度: AIを停止した際の代替の難しさ、0〜100%。導入だけでは増えず、「業務統合」を研究して一定以上の導入とサービス提供を続けると進む。
- 導入は浸透の足掛かりとなり、依存は意思決定への継続介入を強める。ただし導入・依存だけでは国家支配にならない。
- 提供中のサービスが止まると、依存度に応じた経済・インフラの損失が一度発生する。停止中に毎日同じ損失を重ねない。
- 依存度60%以上の国では、人間側が停止損失を恐れて施設隔離を延期し、監査へ切り替える。ただし警戒度85%以上では延期しない。最終停止作戦への免疫ではない。
- 交通は経路の両端の国の経済・インフラに応じて減る。描画によってゲームの乱数や勝敗を変えない。

勝利条件は従来の支配率90%以上を10日維持。敗北条件も維持する。

## ニュースと会話

ニュース5種類: 研究成果の公開、行政導入の拡大、基幹業務への定着、監査・権限制限、不正介入の報道。条件を満たす国で発生し、実際にその国の数値を変える。世界全体で120日の間隔を空け、同じ記事を同じ国へ再発行しない。国の処理順によって発生先が変わらないようID順に選ぶ。

12件の会話に研究条件付きの追加選択肢を1つずつ設定。未研究の選択肢は必要研究を示して無効化し、エンジン側も不正な選択を拒否する。成果を公開する、基幹業務へ統合する、人間の代替手段を残す、といった違いを持たせる。

会話は中規模以上の組織的な意思決定を中心とする。対応後の間隔は90日、未対応の依頼は180日で失効。依頼が届いただけではゲームは止まらず、開いている間のみ停止する。無視しても次の相談を永久に塞がない。

## 完了通知

右上に1件ずつ独立した板を上から積む。まとめた背景板や常設ログは置かない。研究・施設侵入・制御権確立・増強・復旧・SNS・会話の完了、国家掌握、ニュースや重要な停止警告を表示する。数値の毎tick変動や配分量の変更では通知しない。

各板は表示から実時間7.5秒で消える。ゲームの一時停止や倍速とは独立。最大4枚を同時に表示し、残りは順番に表示する。再開始で前のプレイの通知を消す。通知が地図操作を遮らないようクリックを透過する。

## 展示の色調について

色調変更は指示ではなく相談として扱い、今回は適用していない。重厚な路線を維持し、地図の中間調・文字・選択状態の視認性を上げる方向を推奨する。文化祭では遠目からの読め方と最初の操作の分かりやすさを優先して調整する。
