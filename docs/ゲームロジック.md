# 世界制御シミュレーション

## 実装範囲

既存のReact・TypeScript・Vite・Zustand構成、採用済みの地形背景・海・110m国境・横方向カメラを維持している。新しい画像素材やバックエンドは追加していない。

- 地図上の177か国に、インフラ・経済・政治的統制・AI浸透・意思決定支配・対AI能力・AI受容・警戒を設定。
- 指定された実施設を元にした施設44件、施設カテゴリ9種。既存には施設配置データがなかったため追加。日本3件、米国7件、中国6件、ロシア5件。
- 施設の侵入、限定アクセス、制御権確立、稼働モード3種、作戦3種、3段階の設備増強、隔離復旧。
- 容量型の演算資源。侵入・研究・浸透・防衛・SNS・増強・復旧で共有。
- 5系統・15スキル。前提研究、進捗保持、割当変更、能力解放。
- 重要人物8人・条件付き会話12件。各4択（うち1つは研究条件付き）、国家への効果と信頼値を保持。
- SNS作戦5種。地域発信、世論分析、多言語広域発信、合成コンテンツ。
- 人類の5段階の対応、調査・研究・情報共有・隔離・奪還の5行動、最終停止作戦。
- 国家のネットワーク波及、支配の維持と解除、勝利・敗北、原因表示、シードと設定編集。

## 起動・検証

```sh
npm ci
npm run dev
npm test
npm run build
npm run test:browser
npm run simulate -- 2600 3
```

通常の開発サーバーは `http://127.0.0.1:5173/`。ブラウザーテストは専用の5188番ポートを利用する。自動シミュレーションの引数は最大日数と各戦略の試行数。Node.jsはTypeScriptの型除去を利用できるバージョンが必要（検証環境はNode.js 24）。

ブラウザーテストは画面操作・モバイル幅・採用済み地図の維持を確認し、`test-results/`へ実画面を保存する。自動シミュレーションは5方針を比較し、100日間隔の演算容量・支配率・浸透・警戒・停止作戦の推移を`reports/simulation.json`に記録する。

## 操作と最初の進め方

1. 最初は一時停止。地図上の神戸の施設アイコンから富岳へ接続する。
2. 「制御権を確立」で限定アクセスから通常の施設支配へ移行。利用モードを選ぶ。全面利用は容量と露見をともに増やす。
3. 「研究」で侵入経路解析へ計算資源を4程度割り当て、1×で進行する。届いたチャットに返信する。
4. 海外の計算施設を確保し、演算容量と研究を拡張する。第2階層以上の強い施設操作には深層制御が必要。
5. 国家を地図から選び、浸透へ容量を割り当てる。意思決定モデルの研究で、十分浸透した国家への意思決定介入が始まる。
6. 国際網統合で、施設のない国へも接続ネットワークを通じて意思決定支配を広げる。施設のない国へ直接浸透を割り当てることもできる。
7. 警戒が上がったら、利用モード・施設の潜伏作戦・国家の防衛割当・SNS分析・退避研究で対処する。

国・施設はクリックとキーボードで選択できる。施設が密集する場所では施設一覧を利用する。補助パネルを閉じれば地図へ戻る。通常のパネルを開いても時間は進み、チャットを開いて返信を選んでいる間はエンジン側も時間を停止する。

「演算」で全作戦の割当と優先度を変更できる。供給不足では高優先度→作成順に容量を確保し、入らない作戦を停止。停止中の進捗は保ち、供給回復時に再開する。手動で中止しても研究進捗は保持するが、侵入はやり直しになる。

## 状態とtick

`GameState`が唯一のシミュレーション状態。描画用のカメラや選択は別の`mapStore`に保持する。

```ts
const state = createInitialState(countries, 42);
const ordered = applyAction(state, {
  type: 'allocate', kind: 'research', target: 'intrusion', capacity: 4,
});
const next = simulateTick(ordered);
const compute = computeState(next);
const world = worldMetrics(next);
```

いずれの関数も入力状態を書き換えない。乱数の内部状態は`GameState.rng`に保存する。人類の対象・行動選択でのみシード付き乱数を使用し、描画では乱数を使わない。同じ初期値・シード・命令なら結果を再現できる。

1tickは1日。初期速度は1秒/tickで、0.5×・1×・4×・16×、一時停止、1tick送りが可能。秒/tickや主要係数はデバッグパネルまたは`BALANCE`で変更できる。25分で強制終了するルールはない。

tickの順序は以下。国家の因果計算はtick開始時のスナップショットを参照し、配列の順番に依存しない。

1. 命令、供給計算、優先度による稼働判定
2. 侵入と設備増強・復旧の進行
3. 施設の継続効果、稼働痕跡、研究とSNS
4. 国家への演算投入、接続ネットワークへの波及、意思決定介入
5. インフラ・経済・行政・受容の回帰、警戒と対抗能力の更新
6. 観測された異常に応じた人類の対応と停止作戦
7. 条件付き会話、国家支配の判定、世界支配率と勝敗
8. 容量の再計算、原因と履歴の保存

演算容量は施設の基本容量×増強段階×経済稼働係数×インフラ供給×利用モード×アクセス権限×産業支援×研究補正で計算する。社会インフラへの妨害は、自軍の供給も低下させる。

受容や施設だけでは国家支配にならない。浸透は接続経由で広がるが、継続浸透への稼働中割当がなければネットワーク波及を止める。意思決定の継続介入には研究が必要。社会状態には減衰と基準への回帰がある。

## 勝敗

- 国家支配成立: 浸透70以上、意思決定支配70以上、対AI能力55以下。
- 支配解除: 浸透または意思決定が50未満、あるいは対AI能力75超の状態が12日継続した場合。
- 世界支配率: 支配成立国の影響力ウェイトの合計。全国家のウェイトは合計100。浸透進捗とは別の値。
- 勝利: 世界支配率90%以上を10日継続。
- 敗北: 生存拠点と容量を喪失した状態が25日継続、または最終停止作戦が140進行。
- 警戒100での即死はない。最終停止には世界の緊急警戒、一定の対抗能力、露見した施設が必要。防衛割当で進行を後退させられる。

隔離は一時的に供給を停止し、期限終了か復旧作戦で限定接続へ戻る。ただし人類が先に奪還すれば接続を失う。露見していない施設を人類が直接隔離することはない。

## 原因の確認

- 国家パネルの「直近tickの変化要因」は、各数値への演算投入・施設・隣国・減衰・基準回帰・上下限処理の寄与を表示する。
- `state.causes[countryId]`にその国の最新tickの寄与を保存する。
- `state.logs`に研究・侵入・隔離・会話・命令拒否・支配変化などの最新500件を保存。発生tick、国家、発生元、数値変化量を持つ。
- 容量低下は施設の隔離履歴、稼働モードの変更履歴、演算パネルの供給一覧、国家のインフラ・経済の原因明細で追跡する。

全tickの全変数の履歴を無制限には保持しない。長期推移は自動シミュレーションのJSONを使う。

## 主なファイルと追加方法

| ファイル | 役割 |
| --- | --- |
| `src/game/types.ts` | 状態・命令・効果・バランス設定の型 |
| `src/game/data/` | バランス・施設・スキル・会話などの定義データ。分類は `src/game/data/README.md` を参照 |
| `src/game/data.ts` | 型付きの読み込みと施設ID索引 |
| `src/game/causality.ts` | JSON因果式の検証と日次計算 |
| `src/game/engine.ts` | 初期化、命令検証、容量計算、tick、原因記録 |
| `src/game/outcome.ts` | 世界の集計、勝敗判定 |
| `src/game/strategies.ts` | 検証専用の5方針の自動操作 |
| `src/state/gameStore.ts` | エンジンを呼ぶZustandストア |
| `src/components/GameApp.tsx` | HUD、施設・国家・研究・演算・SNS・通信・デバッグパネル |
| `src/components/WorldMap.tsx` | 既存地図と国家状態の色表示 |
| `scripts/simulate.ts` | UIなしの戦略比較 |
| `tests/game.test.ts` | ルールの自動テスト |

通常の内容追加は`src/game/data/`内のJSONを編集する。`data.ts`にゲーム定義を直接追加しない。

- **日次因果関係**: `simulation/causal-rules.json`の`signals`・`rules`を編集。国家指標間の正負の影響、条件、係数を定義する。
- **施設**: `simulation/facilities.json`へID・名前・国家・座標・カテゴリ・階層を持つオブジェクトを追加。IDは明示し、既存IDを変更しない。
- **施設効果**: `simulation/categories.json`の`effects`へ`{metric, amount, scope}`を追加。研究・増強支援は`research`・`expansion`で指定。
- **スキル**: `simulation/skills.json`へID・系統・説明・前提ID・研究量・ボーナス・必要に応じて能力名`unlock`を追加。新しい種類の能力にはロジックとUIも必要。
- **人物・会話**: `events/people.json`・`events/chats.json`を編集。会話にはID・発生条件・各選択肢の効果を明示する。
- **SNS・人類行動**: `events/sns.json`・`events/human-actions.json`を編集。共通のEffectを使う。
- **国家・接続**: `simulation/countries.json`の`profiles`・`overrides`・`weights`・`regions`・`hubs`・`links`を編集する。
- **バランス・利用モード**: `simulation/balance.json`・`simulation/modes.json`を編集。新しい勝利モードの実装は`outcome.ts`に集約する。

## 暫定部分と既知の課題

- セーブ・ロードは今回追加していない。ページ更新・再開始で最初へ戻る。
- 施設はユーザー指定の実施設を参照し、人物は架空。国家の基準値、影響力、地域接続はゲーム用の抽象化。実際の通信網や政治情勢は再現しない。
- 人物の信頼値は記録・表示するが、会話の分岐にはまだ使わない。
- 人類の行動は条件と重みによる抽選。SNSへの対抗は国家の対AI能力を通じて表現し、SNSアカウント単位の停止は未実装。
- 施設の手動「制御権確立」は限定アクセス成功後の即時操作。増強・侵入・隔離復旧は時間と容量を必要とする。
- 地域ネットワークにより中盤以降の浸透が100に張り付きやすい。終盤の主な制約は意思決定支配と防衛になる。
- 防衛優先は低警戒のまま進めやすいが、演算不足で長期化する。5方針は検証用の簡易操作で、人間の最適戦略や勝率を保証しない。
- 開始から25分は固定制限ではなく調整の目安。自動プレイ時間に、人間の操作・相談中の一時停止時間は含めない。

検証結果と戦略比較の実測は`docs/検証結果.md`を参照する。
