# UIの方針

衛星地図を主役とした、落ち着いた指令室の画面にする。

- 色・書体・面の質感は `theme.css`、ボタン・入力・パネルは `Primitives.module.css` に集約する。
- 通常の文字は灰白、操作と選択は琥珀、稼働・完了は緑、危険・停止は朱色とする。色だけに頼らず、状態名やアイコンも表示する。
- 日付と進行速度をまとめ、会話による時間停止も明示する。
- 状態から案内する作戦目標と、最終的な勝利条件を分けて表示する。作戦目標は折りたたみ可能にする。
- 資源配分では、配分できる量、実行中の状態、実行できない理由、反映結果を示す。判定は既存のゲームルールと一致させる。
- 未解放の研究も詳細を閲覧可能にし、前提条件を明示する。
- 通知は右側の操作パネルと分離する。狭い画面でパネルを開く場合は通知を見出しだけの表示にする。
- パネルは縦スクロール、狭い画面の研究ツリーは横スクロールを使う。地図や下部メニューにはみ出す固定寸法を追加しない。
- 操作部品にはフォーカス表示を付ける。装飾的な動きは控え、動きを減らす設定を尊重する。

UI変更時は開始直後、施設の限定アクセス・掌握・隔離、研究前・研究中・研究完了、資源不足、人物との対話、勝敗を確認する。展示機の解像度で日本語と主要操作を実画面確認すること。ビルドや静的HTMLでの確認だけでは、視覚的な完成を判断しない。
