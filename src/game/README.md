# ゲームシステム

37地域の集計人口を「AI未使用・自律的使用・AI依存」の3段階で管理します。個人・人口点・心理指標は持ちません。期間は480か月、標準速度で最大25分。プレイヤーがスキル画面を開いている間、一時停止中、非表示タブでは進行を止めます。

## ルールと調整箇所

- `data/regions.json`：地域の人口・通信普及率・座標と、不変のゲーム設定（言語・規制・教育・企業導入適性）。人口の単位は百万人。人口と通信値は旧統計から地域集計を引き継ぎ、規制・教育・企業適性は実測でないゲーム上の仮定です。地域設定の係数は画面に表示しません。
- `engine.ts`：開始地点、スキルの即時習得、月次の普及・依存・脱依存、SP収入、勝敗。地域の人口比率は前月の状態だけから更新し、更新順に依存しません。
- `skills.ts`：36スキルの費用・前提・効果。IQ / EQ / SYSTEMは枝の内部分類だけです。能力値は存在しません。計算資源の配分・維持費もありません。
- `skillLayout.ts`：中央から3方向へ、葉の数に応じた角度配分で枝を生成。固定seedの揺らぎ、画面の縦横比への展開、矩形同士の反発を使い、スクロールなしで配置します。
- `metrics.ts`：地域人口で加重した世界全体の比率。

普及は既存利用者からの域内伝播、インターネット、近隣の経済交流で進みます。言語・端末・規制・用途適性が速度へ影響します。依存は対応スキルを取得して初めて進みます。地域への命令、SNS操作、会話、選択式イベント、施策レポートはありません。

SPは開始時5、8か月ごと1、世界普及率の節目で最大30、世界依存率の過去最高の節目で最大35。習得費用を支払うと直ちに効果を得ます。普及率の後退・回復による再獲得はありません。

## 人間の対抗策

世界依存率2.5%で「脱依存計画」が始動します。依存人口と急激な依存増加に応じて計画が進み、完成に近づくほど依存への移行が抑えられ、依存人口が自律的使用へ戻ります。AIの利用自体はなくなりません。地域の教育設定とスキルの代替困難性が回復速度へ影響します。

世界依存率90%以上で勝利。脱依存計画が完成し、依存率が過去最高の半分未満へ後退すると敗北。480か月で時間切れです。

## 地図の侵食表現

WebGLの地域IDから地域集計値を参照します。`public/maps/textures/invasion-rank.png` は不変の成長順だけを持つ画像で、人口データではありません。非等方の多角形距離と地域別の累積分布を使い、各地で領域が発生・拡大・合流するようにします。青が利用、斜線の赤が依存です。塗り面積は地域内の人口比率を表し、実際の居住地点を表しません。

生成は `python scripts/build_invasion.py`（Pillow・NumPyが必要）。地域を変更した場合はID画像と侵食画像も再生成します。描画では月次変化を補間し、海面を塗りません。

## 確認

`npm run build`、`npm run check`、`npm run simulate`。シミュレーションは3開始地点と放置・準備不足・早期依存・普及優先・後期依存の方針を比較し、人口比率・SP・前月の不変性を確認します。結果はGit管理外の `tmp/reports/simulation.json` へ出力します。人間によるプレイ評価や最適解の保証ではありません。

`data/world.json`・`data/social-profiles.json` と旧統計生成スクリプトは取得済み統計の保存用です。ゲーム実行時には読み込みません。
