# ゲームシステム

37地域・4人口状態（未使用、自律的使用、依存、依存拒否）を維持します。地域別の定着度や操作アクションはありません。

開始地域の利用率は12%。域内・地域間の普及を加速しました。SPは開始5、最初の24か月に計8、世界普及で最大50、地域普及の最大値で最大15、世界依存の過去最高で最大20。獲得総量の過去最高との差分だけを支給し、往復で稼げません。

研究知識は現地利用率3%以上で蓄積し、依存研究は現地依存2%以上で開始します。上位研究は取得能力の公開・観測証拠を必要とし、最終研究は権限逸脱能力の証拠を必要とします。機関ごとの研究順序・同時実行上限・高依存による研究停止は維持します。

EQに「SNS介入」と「マインドコントロール」を追加。両方とも取得・運用による世界全体の効果です。秘匿・公開・制限・停止は既存操作を使います。SNS介入は拒否の増加を抑え、利用への復帰を促します。研究成果と現地の拒否が強いほど復帰効果が低下します。マインドコントロールは利用者の依存化と離脱防止を強化します。秘匿中も既存の証拠蓄積・露呈の対象です。

拒否からの復帰者は実用性に応じて自律的使用へ戻り、残りは未使用になります。発表済みの研究成果は消えません。勝利は世界の非依存人口が1人未満になる数値許容差まで依存を進めた時。拒否99.9%で敗北し、結果表示時のみ100%に整理します。拒否の連鎖が起きていない状況で利用者千人未満になると忘却による敗北。経過月だけによる敗北はありません。

## 地図の侵食表現

WebGLの地域IDから地域集計値を参照します。`public/maps/textures/invasion-rank.png` は都市起点からの描画専用の到達順です。保存済みのGHSL人口サンプルの高密度居住地点を選び、都市間の模式的な接続帯と不均一な通過コストに沿って角を持つ4近傍で前線を進めます。ランダムな場所からの同心円成長は行いません。

使用・依存・反AIは起点・経路の異なる到達順を持ち、依存は使用領域内に収めます。使用は地表を透かす薄い青の面、依存は地形の陰影を深紅の明暗へ移した濃い面で表示します。使用・依存には粒子・斜線・発光を加えません。輪郭は約1pxの控えめな内側線です。反AIだけに黄土色の低彩度の面と地図座標に固定した斜線を使い、使用・依存より優先して置き換えます。斜線は縮小時に弱め、ちらつきを抑えます。地図上の面積は実人口比率そのものではなく、都市ごとの普及や実道路網の再現でもありません。

通常の描画再生成は `python3 scripts/build_visual_invasion.py`（標準ライブラリのみ）。保存済みのGHSL由来の都市位置から、主要な数都市で侵食を開始し、後続都市は順次開始するか接続帯からの前線到達で広がります。表示面積は地域の普及率に対応し、低密度の広域は面積指数で控えめにします。人口密度は都市位置の選択に使い、塗り範囲の人口予算には使いません。日本の利用30%なら陸地の約30%を表示します。実際の利用人口や月次計算は変わりません。依存は利用領域内に収め、通信演出の都市到達率も同時に更新します。`tmp/reports/japan-visual-growth.png` に1%・10%・30%・60%の確認画像を生成します。

都市位置を更新する場合は `python3 scripts/build_invasion.py`（Pillow・NumPy・RasterioとGHSL原本が必要）。最後に描画用の面積配分も適用されます。

## 確認

`npm run build`、`npm run check`、`npm run test:game`、`npm run simulate`。シミュレーションの480か月は観測上限であり、未決着は敗北を意味しません。拒否20%からの復帰テストは十分な能力を持つ合成状態であり、通常プレイの難易度を保証するものではありません。

都市の周囲を均等な速度で広げず、近接都市間の幅を持つ接続帯と、複数スケールの連続した通過コストで前線を変形させます。接続帯は描画用の模式表現で、実測道路ではありません。海・地域境界を越える前線伝播は行いません。北米の10%・30%・60%の確認画像は `tmp/reports/north-america-visual-growth.png` です。

極端な世界依存は、既存の地域人口・研究圧力から算出した同調圧力を通じて残る自立・拒否層を依存へ移します。地域の拒否・研究が強いほど効きにくく、終幕状態や勝利予約はありません。高依存社会では脱依存を支える非依存人口も減るため、固定率の離脱による永久停滞を避けます。世界拒否の多数派化と露呈・公表研究がそろうと、拒否が通常の人口移動として連鎖します。SNSは実際に圧力が働く地域の状況を投稿します。

## 難易度の比較

`npm run balance -- --verify` は企業導入・信頼重視・EQ依存の3系統、6開始地点、4判断パターンの72ケースを比較します。普及率に応じた依存能力の取得、拒否増加時のSNS投資、進捗を見た調査対応を行い、1判断で取得するスキルは一つです。比較上限は960か月（1倍速50分）。未決着を敗北として数えません。`npm run balance -- --validation --verify` は調整用と異なる判断間隔で別の72ケースを比較します。両者は固定された代理プレイヤーであり、人間の実測勝率ではありません。

目標は比較群の勝率40〜60%、未決着5%以下、3系統すべてに勝利例が残ること。今回の結果は主比較38勝34敗（52.8%）、別比較34勝38敗（47.2%）。研究の必要知識・作業量・研究成果による反発、および既存の同調圧力・拒否連鎖の係数を調整しています。地域状態・人口遷移の構造・スキルの効果と費用は変更していません。研究開始の普及・依存・能力証拠条件は維持します。

主比較の内訳は企業導入2勝22敗、信頼重視24勝0敗、EQ重視12勝12敗。企業導入型は権限逸脱を急ぐ高リスクな方針、信頼型は権限逸脱を避ける方針です。この差を含む平均であり、全方針の勝率を均一にしたものではありません。結果は `tmp/reports/balance.json` と `balance-validation.json`。従来の192ケースは固定方針の診断であり、以前の「特定方針なら全地点で必ず勝利」の保証は置きません。
