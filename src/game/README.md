# ゲームシステムの構成

`engine.ts` が1か月の進行を調整します。各モジュールが返す新しい状態をZustandへ渡し、前の状態は変更しません。人口点は4,000個、期間は480か月、1か月3,125msで標準速度25分です。重要イベントの選択中・ヘルプ・非表示タブでは時間が止まります。

- `initialState.ts`：ゲームの初期化と生活圏ネットワーク。
- `population.ts`：GHSLの位置を保持し、WPP・ITU・UIS・World Bankの国別初期条件を代表人口へ配分。欠測と仮定を区別。
- `skills.ts`：17スキルの必要研究量・前提・排他・効果対象・リスクと、習得スキルからの能力計算。
- `research.ts`：有限の算力の配分・研究進捗・完了時の能力更新。
- `areaDynamics.ts`：0〜4の分野別統合、介入の波及、教育→労働→行政の連鎖。
- `populationDynamics.ts`：世代交代、基準値への自然回帰、近隣・地域制度を用いた確率的な段階遷移。前月の点群を参照し、走査順で結果が変わらない設計。
- `interventions.ts`：SNS・社会投資と共通の影響適用処理。影響人口・段階変化人口・信頼／警戒の変化をレポート。
- `conversations.ts`：立場ごとの2〜4往復の会話。スキルに応じた選択肢と協議履歴。
- `events.ts`：架空の社会イベント、解放条件、選択肢・失敗・無対応の影響。地域を越える制度協議も生成。
- `metrics.ts`：代表人口で加重した集計と敗北前の警告。
- `predictions.ts`：比較用の不確実なシナリオ予測。将来の保証値や実測予測ではない。

## 数値の単位と更新

人口点の心理・社会指標は0〜100。画面用の集計値と地域の信頼・警戒・安定・自律性回復制度は0〜1、分野統合は0〜4です。統計は `data/statistics/README.md` に出典と限界を記載しています。

心理値は `現在値 + 外部影響 + 回帰係数 × (基準値 − 現在値)` で更新します。SNSによる短期効果は回帰し、制度の実績・教育経験・世代交代は基準値を変更します。教育経験は若年期に累積し、就職時にも保持します。学歴だけで依存度は決まりません。

灰→青は自然普及します。青→赤には制度・介入の履歴・近隣の判断委譲が影響し、赤→紫には自動意思決定、SYSTEM52、対象分野2.7、行政2.4が必要です。警戒・自律性回復制度・障害は逆方向の遷移を起こします。

供給算力を人間のインフラと自身の研究に継続配分します。研究中のスキルへ投入したCUに時間を掛けた仕事量（CU・月）が蓄積し、必要量に達すると能力を獲得します。通貨として貯めたり、RPで購入したりする方式はありません。研究へ多く回すほどインフラ不足の危険が増します。研究停止・完了時の算力はインフラへ戻り、切り替え前の研究進捗は保持します。社会投資で供給を増やし、透明性と秘匿は同時に選べません。

## 勝敗と検証

代表人口95%以上が紫で支配達成。全点一致を要求して確率的な世代交代で終了できなくなることを避ける判定です。世界信頼20未満36か月、社会安定20未満24か月、人口70%以上で自律性回復制度が定着、40年経過で敗北します。

`npm run simulate -- 3` は放置・透明性・研究投資・秘匿の4方針を複数seedでプレイします。勝敗だけでなく、人口保存・数値範囲・研究予算を確認し、経過は `tmp/reports/simulation.json` に出力します。これは最適解の保証や、人間による遊びやすさの評価を置き換えるものではありません。
