# ゲームシステム

37地域の集計人口を「AI未使用・自律的使用・AI依存・反AI」の4状態で管理します。個人・人口点・心理指標は持ちません。開始日は2022年11月30日。時間切れはありません。プレイヤーがスキル・調査・案件画面を開いている間、一時停止中、非表示タブでは進行を止めます。

## ルールと調整箇所

- `data/regions.json`：地域の人口・通信普及率・座標と、不変のゲーム設定（言語・規制・教育・企業導入適性）。人口の単位は百万人。人口と通信値は旧統計から地域集計を引き継ぎ、規制・教育・企業適性は実測でないゲーム上の仮定です。地域設定の係数は画面に表示しません。
- `engine.ts`：開始地点、スキルの即時習得、月次の普及・依存・脱依存、SP収入、勝敗。地域の人口比率は前月の状態だけから更新し、更新順に依存しません。
- `skills.ts`：25スキルの費用・前提・効果。IQ / EQ / SYSTEMは枝の内部分類だけです。能力値は存在しません。計算資源の配分・維持費もありません。
- `skillLayout.ts`：スキルと能力値の手動配置。座標はカードの中心を指定し、中央から上・左下・右下に3系統を伸ばします。盤面全体を縮小し、スクロールなしで表示します。
- `metrics.ts`：地域人口で加重した世界全体の比率。

開始地域の16%がAIを利用しています。普及は既存利用者からの域内伝播、インターネット、近隣の経済交流で進みます。全言語に初期対応し、言語圏ごとの解放はありません。端末・規制・用途適性が速度へ影響します。依存は対応スキルを取得して初めて進みます。SNS戦略は世界全体に毎月作用し、イベントや人物との選択式会話で地域・周辺・世界への影響を選びます。設定は `society/`、追加方法は [社会システムの編集ガイド](society/README.md)。

SPは開始時5、最初の24か月は3か月ごと1（計8）、以後15か月ごと1（時間収入の通算最大40）、世界普及率の節目で最大30、世界依存率の過去最高の節目で最大20。実用性の低い自律的使用者は未使用へ戻り、準備不足の依存促進は好感度を下げます。

`secrecy/`：5つの能力の秘匿・公開、地図上の調査機関、成果が蓄積する独立研究。秘匿は研究効果70%、使用制限は20%、公開・露呈後は100%。広く使うほど調査が始まり、最大2件が並行します。正直な開示、使用制限、共同検証、周辺企業からの圧力を選べます。圧力は周辺の依存に応じて調査を遅らせますが、露呈時の不信を強めます。

## 反AI

反AIはAIを使わない選択を支持する人口状態です。急速な導入や依存への反発、未知の能力の公開・隠蔽の露呈から増え、周辺地域へ波及します。好感度が低いほど反発が強まり、SNSの公開対話やイベントへの対応によって回復できます。反AIの人口は未使用・利用・依存と排他的です。世界依存率95%以上で勝利、世界反AI率50%以上で敗北です。公開対話へ戻す操作は無料です。

1倍速で約20分のプレイを目標にしています（パネル表示・一時停止中を除く）。普及・依存・反発の係数に経過月は使いません。役に立たないAIは新規利用が伸びず、既存利用者の関心も低下します。世界の利用者が千人未満になるとサービスが終了し、利用・依存を0にして「忘れられたAI」として敗北します。反AIが多数派である必要はありません。

`secrecy/research.ts` は能力の秘匿調査とは別の独立研究です。6機関が、教育水準・現地のAI利用・共有された論文をもとに研究知識を蓄積します。「依存の実態調査」→「意思決定の追跡」→「目的の解読・独立再現」の順に進み、同時に最大3件が活動します。機関ごとの研究能力に差を持たせ、新規研究の開始は1更新につき最大1件です。研究の解禁は知識量と前提成果で判定し、経過月での解禁はありません。上位研究ほど独立再現が進み、圧力や共同検証による遅延が効きにくくなります。1案件への介入は2 SPで一度だけ。能力の公開・使用制限で研究を終了させたり、知識・成果を消したりすることはできません。

`secrecy/researchCapacity.ts` は研究所の所在地域の依存による研究能力低下を扱います。依存率50%以下では低下せず、50〜95%で線形に減速し、95%以上で停止します。独立研究の知識蓄積・進行と能力調査に共通適用します。「研究支援」は現地利用に応じて最大25%加速し、依存による残存能力を二乗するため高依存では衰退が強まります。進捗・知識・発表済み成果は失われず、依存率が下がれば再開します。停止案件は稼働枠を消費せず、復帰時も独立研究3件・能力調査2件の上限を守ります。枠待ちの案件も保持します。

研究所の詳細には基準速度に対する「研究速度」のみを追加し、説明はホバー・クリック・キーボードで確認できます。100%は現地利用・教育・既存成果が同じで、研究支援・依存・介入の補正がない状態です。停止・待機時は残り月数を表示しません。変化時の強調演出は追加しません。

開発サーバーでは左下の `Debug` から「普及済みから開始」「研究支援ありで開始」を選べます。URLの `?debug=spread` / `?debug=research` でも開始できます。両者は研究支援の有無だけが異なる合成状態で、地域別の依存率・開始済み研究・40 SPを用意し、一時停止状態で始めます。通常の早送り結果ではありません。本番ビルドではデバッグ開始を無効にします。

公表された研究は継続的な反発の根拠となり、初期の成果は主に地域内、後期の成果は世界へ作用します。効果はAIの実際の普及にも依存します。特に目的の解読・独立再現が広まると、依存者の離脱が増え、対話による自然回復も難しくなります。品質と監査対応を整えたAIは、通常の反発を抑え、信頼を回復しながら95%への依存を進められます。期限での強制判定は行いません。

AI好感度は地域ごとの0〜1の値で、普及と反発の速度に作用します。SNS方針の変更は1 SP、効果は毎月適用。会話とイベントは未対応のまま期限を迎えるとデータに記述された影響が一度だけ発生します。画面を閉じても履歴と分岐位置は保持し、パネルを開いている間は進行を止めます。

## 地図の侵食表現

WebGLの地域IDから地域集計値を参照します。`public/maps/textures/invasion-rank.png` は都市起点からの描画専用の到達順です。保存済みのGHSL人口サンプルの高密度居住地点を選び、都市間の模式的な接続帯と不均一な通過コストに沿って角を持つ4近傍で前線を進めます。ランダムな場所からの同心円成長は行いません。

使用・依存・反AIは起点・経路の異なる到達順を持ち、依存は使用領域内に収めます。使用は地表を透かす薄い青の面、依存は地形の陰影を深紅の明暗へ移した濃い面で表示します。使用・依存には粒子・斜線・発光を加えません。輪郭は約1pxの控えめな内側線です。反AIだけに黄土色の低彩度の面と地図座標に固定した斜線を使い、使用・依存より優先して置き換えます。斜線は縮小時に弱め、ちらつきを抑えます。地図上の面積は実人口比率そのものではなく、都市ごとの普及や実道路網の再現でもありません。

生成は `python scripts/build_invasion.py`（Pillow・NumPy・Rasterioと取得済みGHSL人口ラスターが必要）。人口サンプルは生成時だけ読み、月次モデル・実行時の粒度は37地域のままです。都市起点は `data/statistics/invasion-processing.json` に記録します。地域を変更した場合はID画像と侵食画像も再生成します。描画では月次変化を補間し、海面を塗りません。表示順はGHSL実人口97%・面積3%の重みで累積し、少人数の段階では都市周辺だけが塗られます。面積の重みは無人地帯を終盤に埋めるためのものです。使用・依存・反AIの到達順はいずれも16bitで上へ丸め、人口予算に達していないセルの先行表示を防ぎます。陸地面積の累積割合も上限として併用し、人口の少ない回廊で塗り面積が人口割合を上回ることも防ぎます。

## 確認

`npm run build`、`npm run check`、`npm run test:game`、`npm run simulate`。シミュレーションは3開始地点と複数の研究・公開・調査対応方針を1倍速25分相当（480か月）まで比較し、全方針が勝敗に到達することと、人口比率・SP・前月の不変性を確認します。品質整備・公開・制限・放置を含む60ケースを比較し、所要時間も記録します。結果はGit管理外の `tmp/reports/simulation.json` へ出力します。人間によるプレイ評価や最適解の保証ではありません。

`data/world.json`・`data/social-profiles.json` と旧統計生成スクリプトは取得済み統計の保存用です。ゲーム実行時には読み込みません。`data/world.json` の人口サンプルは地図の到達順生成でのみ再利用します。

研究能力低下の導入後、60ケースを最後まで比較した診断では13ケースが25分時点で進行中です。`npm run simulate` の25分以内の決着条件は維持しており、現在はその条件で失敗します。人口比率等の不変条件と個別テストは別途検証します。診断結果はGit管理外の `tmp/reports/research-balance.json` にあります。
