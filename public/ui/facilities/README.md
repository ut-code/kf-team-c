# 施設アイコン

全9カテゴリは平面的なv4を採用。計算施設と産業施設も再生成前のv4へ戻した。原本は `tmp/facility-icons/` の各カテゴリ名に `-color-v4.png` を付けたファイル。配信用PNGは原本を128×128へLanczos縮小し、透過を維持して保存する。

`src/map/sprites.ts` が画像と半透明の黒い円背景をアトラスへまとめ、`src/map/WorldRenderer.ts` がWebGLで描画する。施設アイコンの描画と当たり判定は有効。円背景やサイズは `sprites.ts` で管理する。

黒い円背景は直径26px、内側の画像は従来どおり余白込み26pxとし、背景だけを縮めて余白を抑えている。施設右下の状態点は表示しない。近接集約は停止したままで、各施設を地理座標へ個別に配置する。
