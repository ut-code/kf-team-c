# 施設アイコン

全9カテゴリを行政K案の立体表現に統一。行政以外の8点は、v4の形とカテゴリ色を保ち、行政K案をスタイル参照として内蔵画像生成AIで編集した。真正面の記号に、明確な暗色輪郭・深い面取り・左上からの光と陰影を加えている。

行政施設の `government.png` のみK案（J案の立体感を強めた版）へ差し替えた。真正面の形と明確な暗色輪郭を保ち、内側の陰影で強い厚みを表現している。原本は `tmp/facility-icons/government-k-deep-front.png`、生成プロンプトは同フォルダーの `README-government-k.md`。

配信用PNGは採用原本を128×128へLanczos縮小し、透過を維持して保存。施設全体は直径28px、不透明度32%の黒い円。その内側へ余白込み26pxの画像を配置する。施設右下の状態点は表示しない。選択時は円形の輪郭で示す。

試作原本は `tmp/facility-icons/` に保存。行政以外の立体版原本は各カテゴリ名に `-deep-front.png` を付けたファイル。`src/map/sprites.ts` が画像と円背景をアトラスへまとめ、`src/map/WorldRenderer.ts` がWebGLで描画する。

近接集約は描画経路で停止している。各施設を地理座標へ直接配置するため、近接地点では重なりが生じる。
