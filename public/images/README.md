# 地図上の出来事アイコン

`event-marker.svg` は赤い通常の「！」、`chat-marker.svg` は独立した青灰色の吹き出しです。このプロジェクト用のベクター素材で、「！」自体の前面・側面・縁を描き分け、浅い厚みと陰影を加えています。金属枠や装飾バッジは使いません。SVGの下端中央を地理座標に合わせます。

見える画像は32×36 CSS px、クリック範囲は40×44 CSS pxです。地図の移動時はWebGLの描画完了と同じフレームで位置を更新します。
