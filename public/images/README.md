# 地図上の出来事アイコン

画像生成は使用しません。以下のSVGは、このプロジェクト用にコードで記述した図形です。

- `event-marker.svg`：赤い円枠と通常の「！」。
- `chat-marker.svg`：青灰色の円枠と吹き出し。
- `investigation-marker.svg`：イベントと同じ赤い円枠と線画のフラスコ。進捗はアイコン上の細いバーで表示し、数値は右上の通知に表示します。

背景は透過です。側面、金属、ベベルなどの装飾はありません。SVGの下端中央を地理座標に合わせます。

表示は30×33.75 CSS px、クリック範囲は40×44 CSS pxです。地図の移動時はWebGLの描画完了と同じフレームで位置を更新します。イベントの詳細画面も同じSVGを参照します。

地図上の指標、時計、凡例、操作ボタンはHTML/CSSとLucideのSVGで描画し、生成画像は参照しません。以前の `event-marker.png` は未使用の旧素材です。
